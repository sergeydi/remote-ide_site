Features

Everything you need
to code on the go

A complete toolset for developers who work from their iPad — without compromises.

Syntax-highlighted editor

Powered by Runestone and Tree-sitter. Supports Swift, Python, JavaScript, TypeScript, Go, Rust, and 15+ more languages with accurate highlighting.

AI coding agent

Open a dedicated agent window alongside your editor and terminal. Run Claude Code or any AI tool in your SSH session without leaving the app.

Git change tracking

Modified files are highlighted in the project tree. See what's changed at a glance, directly in the file manager — no extra tools needed.

Full SSH terminal

Connect to any Linux server and run commands in a real VT100-compatible terminal. Full ANSI escape code support via SwiftTerm.

iCloud Drive sync

All projects live in your iCloud Drive. Open files in other apps, access them from your Mac, and never lose your work.

One-tap file sync

Push your entire project to a remote server or pull it back with a single tap. SFTP-powered, fully recursive, blazing fast.

SSH key & password auth

Authenticate with a password or private key. Manage multiple servers. All credentials stored securely in the system Keychain.

Quick-input toolbar

A custom row above the keyboard with Tab, brackets, dot, equals, and hash — the keys you actually need when coding on iPad.

Full file manager

Create, rename, delete, and share files and directories. Navigate your project tree with the familiar iOS sidebar.

Saved SSH commands

Build a library of frequently used commands. Run any saved command in your active SSH session with one tap.

Dark & light themes

Automatically follows your system appearance. No manual toggle needed — just open and code.

Split View & Stage Manager

Run Remote IDE alongside a browser or documentation in Split View, or manage multiple IDE windows in Stage Manager — full iPadOS 26 multi-window support.

Privacy

Your code & keys
stay private

Remote IDE does not collect any data. There are no analytics, no telemetry, and no accounts. Everything stays on your device or in your own iCloud.

Your SSH passwords and private keys are stored exclusively in the iOS Keychain — the same secure hardware-backed enclave used by the system itself. They are never written to files, logged, or transmitted to any third party.

  • No accounts or sign-up required
  • No analytics or usage tracking
  • No third-party SDKs or ad networks
  • SSH credentials stored only in Keychain
  • Private keys never leave the device
  • SSH connects only on explicit user action
  • All project files stored in your own iCloud
