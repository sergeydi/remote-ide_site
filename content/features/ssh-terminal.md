<div class="feature-section-text">
<h3>A terminal that actually works</h3>
<p>The SSH console in Remote IDE is powered by <a href="https://github.com/migueldeicaza/SwiftTerm" target="_blank" rel="noopener">SwiftTerm</a> — a full VT100/xterm terminal emulator. It handles ANSI escape codes, colors, cursor movement, and interactive programs the way a desktop terminal would.</p>
<p>Run <code>htop</code>, <code>vim</code>, <code>tmux</code>, interactive Python sessions, or anything else that expects a real terminal. It all works without workarounds.</p>
<ul>
<li>Full ANSI color support (16, 256, and true color)</li>
<li>Cursor movement and in-place screen updates (htop, vim, etc.)</li>
<li>Interactive programs: Python REPL, node, psql, and more</li>
<li>tmux and screen for persistent sessions</li>
</ul>
</div>

<div class="feature-section-text">
<h3>Editor and terminal, side by side</h3>
<p>The terminal lives in the same window as the editor, split vertically. You can drag the divider to give more space to whichever panel you're using at the moment. The split ratio is remembered between sessions.</p>
<p>Switch focus between the editor and the terminal without tapping a tab or navigating away. Both are always visible, always live.</p>
<ul>
<li>Draggable divider between editor and terminal</li>
<li>Ratio persists across app launches</li>
<li>Both panels visible simultaneously on iPad in landscape</li>
</ul>
</div>

<div class="feature-section-text">
<h3>Connection management built in</h3>
<p>The terminal shows a clear overlay when the SSH connection is disconnected or has errored — with options to reconnect, retry, or cancel. You're never left staring at a blank terminal wondering what happened.</p>
<p>When you switch servers, the terminal reconnects automatically. The connection status indicator in the toolbar shows the current state at all times: gray for disconnected, yellow for connecting, green for connected, red for error.</p>
<ul>
<li>Disconnected overlay with reconnect button</li>
<li>Error overlay with retry and cancel options</li>
<li>Color-coded connection status in the toolbar</li>
<li>Automatic reconnect when switching servers</li>
</ul>
</div>
