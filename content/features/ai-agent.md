<div class="feature-sections">

<div class="feature-section-text">
<h3>A dedicated window for your AI agent</h3>
<p>Remote IDE opens a separate window just for the AI agent — its own SSH session, its own terminal, its own state. You can keep your editor and file tree in one window while the agent runs in another, without any tab switching or context loss.</p>
<p>The agent window connects to the same server automatically when you open it. If the connection drops, it reconnects on its own — so you can leave a long agent run going without babysitting it.</p>
<ul>
<li>Independent SSH connection from the main editor window</li>
<li>Automatic reconnect on connection loss</li>
<li>Always forced into dark mode for readability</li>
</ul>
</div>

<div class="feature-section-text">
<h3>Run Claude Code — or anything else</h3>
<p>The agent window is just a terminal connected to your server. Run <code>claude</code>, <code>aider</code>, <code>continue</code>, or any other CLI-based AI tool you already use. No special integration needed — if it runs in a terminal, it runs here.</p>
<p>Because the agent runs on your remote server, it has full access to your codebase, your build tools, your git history, and your environment variables. It can edit files, run tests, commit changes, and push — all without leaving the iPad.</p>
<ul>
<li>Claude Code, Aider, and any other terminal-based agent</li>
<li>Full access to your server's environment and tools</li>
<li>Agent can read, write, and run code like it would on a desktop</li>
</ul>
</div>

<div class="feature-section-text">
<h3>Agent-optimized toolbar controls</h3>
<p>Interacting with an AI agent often means confirming prompts, navigating output, and occasionally nudging a stalled session. The agent window toolbar has buttons for exactly that — without needing to reach for a keyboard.</p>
<ul>
<li>Up / Down arrow buttons for navigating agent prompts and history</li>
<li>Enter button to confirm prompts with one tap</li>
<li>Paste image from clipboard — send screenshots directly to the agent</li>
<li>Quick access to saved SSH commands</li>
<li>Live connection status indicator in the toolbar</li>
</ul>
</div>

<div class="feature-section-text">
<h3>The two-window workflow</h3>
<p>This is where Stage Manager and Split View really earn their place. Open the agent window and your editor side by side — the agent writes code in one window while you review the changes in real time in the other.</p>
<p>The file tree updates automatically as the agent creates or modifies files. You see exactly what it's doing as it happens, without switching away from your review.</p>
<ul>
<li>Agent window runs <code>claude</code> or another tool in your SSH terminal</li>
<li>Editor window shows files as they are modified</li>
<li>Git status panel tracks every change the agent makes</li>
<li>No manual refresh — the file tree reloads on transfer events</li>
</ul>
</div>
